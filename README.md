# Gameplay_Test

### Description
Test exercise for a C++ gameplay interview. The goal is to implement a simple game loop and basic gameplay mechanics.
In Data/Settings.json you can adjust some gameplay settings such as the number of boids, their speed, and the pickup spawn rate.
In Data/city/city.json you can adjust the city layout.

### Gameplay
Move the camera around and shoot as many boid targets as possible. Collect points for each boid hit. The game ends when the player runs out of time.
Randomly spawned pickups can be shot to provide temporary power-ups.

### Controls
Move the camera using the arrow keys or WASD. 
Rotate the camera using the mouse.
Shoot using the mouse buttons.
Ascend/descend using the spacebar and X keys.
